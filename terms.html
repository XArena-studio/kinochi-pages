1. Xizmat nima qiladi

Kinochi -- qonuniy ravishda foydalanish/tarqatish huquqiga ega bo'lgan filmlar asosida qisqa tanishtiruv videolar (Reels/Shorts) yaratadi va ularni ijtimoiy tarmoqlarda joylashtiradi. To'liq film faqat Telegram bot orqali, noyob CODE va kanalga a'zolik tekshiruvidan so'ng taqdim etiladi.

2. Kontent va mualliflik huquqi

Xizmatda ishlatiladigan barcha video/filmlar operator tomonidan qonuniy egalik qilinadigan yoki tarqatish huquqiga ega bo'lgan materiallardir. Xizmat piraciya yoki ruxsatsiz kontentni tarqatmaydi. Agar mualliflik huquqi egasi sifatida o'z materialingiz noto'g'ri joylashtirilgan deb hisoblasangiz, quyidagi bot yoki elektron pochta orqali biz bilan bog'laning.

  • Xizmatni faqat shaxsiy, notijorat maqsadlarda ishlating.

  • Telegram, Instagram, YouTube va TikTok'ning o'z foydalanish qoidalariga rioya qiling.

4. YouTube va TikTok API orqali avtomatik nashr

Xizmat qisqa reklama kliplarini YouTube'ga YouTube Data API (YouTube API Services) orqali, TikTok'ga esa TikTok Content Posting API orqali, operatorning o'ziga tegishli, OAuth orqali ulangan bitta akkauntidan avtomatik joylashtiradi. Bu jarayon:

  • Faqat operator tomonidan oldindan tayyorlangan, qonuniy litsenziyaga ega original kliplarni joylashtiradi -- boshqa foydalanuvchilarning kontentini emas.
  • Har bir joylashtirishdan oldin video sarlavhasi/tavsifi va maxfiylik darajasi (privacy level) belgilanadi; TikTok tomonidan hisobning joriy sozlamalariga mos ravishda taqdim etilgan variantlardan tashqarisi ishlatilmaydi.
