Maxfiylik siyosati (Privacy Policy)

Oxirgi yangilanish: 2026-yil 18-sentyabr

Ushbu sahifa "Kinochi" xizmati (Telegram bot, Telegram kanal va bog'langan Instagram/YouTube/TikTok akkauntlari, birgalikda "Xizmat") foydalanuvchi ma'lumotlarini qanday yig'ishi va ishlatishini tushuntiradi.

1. Qanday ma'lumot yig'iladi

Xizmat Telegram bot orqali foydalanuvchidan quyidagi minimal ma'lumotlarni oladi (Telegram API orqali avtomatik taqdim etiladi):

  • Telegram foydalanuvchi ID raqami
  • Telegram username (agar mavjud bo'lsa)
  • Majburiy kanalga a'zolik holati (a'zo/a'zo emas)

Ijtimoiy tarmoqlarda (Instagram, YouTube, TikTok) joylashtirilgan videolar orqali hech qanday shaxsiy ma'lumot yig'ilmaydi.

2. Ma'lumot nima uchun ishlatiladi

Yig'ilgan ma'lumot faqat quyidagi maqsadlarda ishlatiladi:

  • Foydalanuvchining majburiy kanalga a'zoligini tekshirish (film kodini berishdan oldin)
  • Xizmat sifatini yaxshilash (masalan, qaysi filmlar ko'proq so'ralayotganini bilish)

3. Ma'lumotni uchinchi tomonlarga berish

Yig'ilgan ma'lumot HECH QACHON sotilmaydi va reklama maqsadida uchinchi tomonlarga berilmaydi. Ma'lumot faqat Xizmatning o'z serverida (lokal baza) saqlanadi.

4. Ma'lumotni saqlash va o'chirish

Foydalanuvchi o'z ma'lumotini o'chirishni so'rashi mumkin -- buning uchun quyidagi bot yoki elektron pochta orqali murojaat qiling. So'rov qabul qilingandan so'ng, foydalanuvchiga oid ma'lumotlar 7 kalendar kuni ichida o'chiriladi.

5. YouTube API Services orqali ma'lumotlardan foydalanish

Xizmat filmlarning qisqa reklama kliplarini (Shorts) avtomatik ravishda joylashtirish uchun YouTube API Servicesdan foydalanadi. Bu orqali:

  • Xizmat FAQAT operatorning o'ziga tegishli, operator tomonidan ochiq ravishda ulangan (OAuth orqali ruxsat berilgan) YouTube kanaliga kirish huquqiga ega -- boshqa hech qanday YouTube foydalanuvchisining hisobiga yoki ma'lumotiga kirish yo'q.
  • Olingan yagona ma'lumot -- shu bitta kanalga video yuklash va video holatini tekshirish uchun zarur bo'lgan OAuth token va kanal identifikatori. Bu ma'lumot boshqa uchinchi tomonlarga berilmaydi va faqat video joylashtirish funksiyasi uchun ishlatiladi.
  • Foydalanuvchi (operator) istalgan vaqtda YouTube API'ga ruxsatni Google hisobi xavfsizlik sozlamalari orqali bekor qilishi mumkin; ruxsat bekor qilingach yoki o'chirish so'ralgach, saqlangan token va unga bog'liq ma'lumotlar 7 kalendar kuni ichida o'chiriladi.
  • Xizmat YouTube API Services'dan foydalanadi va shu sababli YouTube foydalanish shartlariga va Google maxfiylik siyosatiga rioya qiladi.

6. TikTok API orqali ma'lumotlardan foydalanish

Xizmat filmlarning qisqa reklama kliplarini TikTok Content Posting API orqali avtomatik joylashtiradi. Bu orqali:

  • Xizmat FAQAT operatorning o'ziga tegishli, OAuth orqali ulangan bitta TikTok akkauntiga (video yuklash va nashr holatini tekshirish uchun) kirish huquqiga ega -- boshqa TikTok foydalanuvchilarining ma'lumotiga kirilmaydi.
  • Joylashtirilayotgan barcha video -- operator tomonidan qonuniy litsenziyaga ega kontent asosida, xizmat tomonidan tayyorlangan original klip; boshqa foydalanuvchilarning TikTok kontenti ishlatilmaydi yoki qayta joylashtirilmaydi.
  • Saqlanadigan yagona ma'lumot -- shu bitta akkauntga tegishli OAuth token. Foydalanuvchi (operator) TikTok akkaunt sozlamalari orqali ruxsatni istalgan vaqtda bekor qilishi mumkin; bekor qilingach token 7 kalendar kuni ichida o'chiriladi.
  • Xizmat TikTok Developer foydalanish shartlariga rioya qiladi.
